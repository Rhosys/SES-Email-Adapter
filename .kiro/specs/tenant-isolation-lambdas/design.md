# Design Document

## Overview

Two new Lambda functions provide tenant-isolated execution environments for untrusted workloads. The **User Code Executor** runs user-authored JavaScript (rule conditions, template functions) sandboxed per accountId. The **Content Sanitizer** parses raw MIME messages, sanitizes HTML, proxies external images, and extracts attachments — isolated per sender eTLD+1.

Both are invoked synchronously by the Main Lambda at specific points in the processing pipeline. A new S3 bucket stores extracted content, served via a new CloudFront origin on the existing distribution. Neither isolated Lambda has IAM permissions to S3 — access is granted exclusively via pre-signed URLs generated by the caller.

## Retention Model

### DynamoDB TTL Durations (ISO 8601)

The following durations are the allowed values for signal/arc retention:

| Duration | ISO 8601 | S3 Lifecycle Tag |
|----------|----------|-----------------|
| 1 month  | `P1M`   | `retention=365` |
| 2 months | `P2M`   | `retention=365` |
| 3 months | `P3M`   | `retention=365` |
| 5 months | `P5M`   | `retention=365` |
| 6 months | `P6M`   | `retention=365` |
| 1 year   | `P1Y`   | `retention=365` |
| 2 years  | `P2Y`   | `retention=3650` |
| 5 years  | `P5Y`   | `retention=3650` |
| 10 years | `P10Y`  | `retention=3650` |
| 100 years| `P100Y` | (no tag — forever) |
| Forever  | `Infinity`| (no tag — forever) |

### Retention Tier Mapping

```typescript
type RetentionDuration = "P1M" | "P2M" | "P3M" | "P5M" | "P6M" | "P1Y" | "P2Y" | "P5Y" | "P10Y" | "P100Y" | "Infinity";

type S3RetentionTag = "365" | "3650" | null; // null = forever (no lifecycle rule applies)

function retentionToS3Tag(duration: RetentionDuration): S3RetentionTag {
  switch (duration) {
    case "P1M": case "P2M": case "P3M": case "P5M": case "P6M": case "P1Y":
      return "365";
    case "P2Y": case "P5Y": case "P10Y":
      return "3650";
    case "P100Y": case "Infinity":
      return null; // forever
  }
}
```

### Retention Source Priority

The effective retention for a signal is determined by (highest priority first):
1. Rule action override (a rule can set `retention` on the signal)
2. Alias-level retention setting (per receiving address)
3. Account-level default retention

The Main Lambda resolves this before invoking the Content Sanitizer, so the pre-signed POST URL already encodes the correct lifecycle tag.

### Signal/Arc TTL Fields

```typescript
interface Signal {
  // ... existing fields ...
  retentionDuration?: RetentionDuration;  // ISO 8601 duration
  ttl?: number;                           // DynamoDB TTL (epoch seconds)
}

interface Arc {
  // ... existing fields ...
  retentionDuration?: RetentionDuration;  // ISO 8601 duration — longest of any signal in the arc
  ttl?: number;                           // DynamoDB TTL (epoch seconds)
}
```

The DynamoDB `ttl` field is computed from `retentionDuration` at write time: `Math.floor(Date.now() / 1000) + durationToSeconds(retentionDuration)`. For `P100Y` and `Infinity`, no TTL is set (item lives forever).

## Integration Points

### 1. Content Sanitizer invocation (replaces S3MimeParser)

The Main Lambda:
1. Resolves the effective retention duration (alias → account → default)
2. Computes the S3 retention tag via `retentionToS3Tag()`
3. Generates a pre-signed GET URL for the specific SES message object
4. Generates a pre-signed POST for the content bucket prefix with the retention tag as a tagging condition
5. Invokes the Content Sanitizer with these URLs
6. Receives back: parsed MIME fields + `urlMapping` (original → CDN path)
7. Applies the URL replacements to `htmlBody` itself (simple string replace, safe — the mapping is data, not code)

```typescript
// Main Lambda — processor integration
const retentionDuration = resolveRetention(accountCtx, emailConfig, ruleOverride);
const s3Tag = retentionToS3Tag(retentionDuration);
const presignedGet = await generatePresignedGet(EMAIL_BUCKET, s3Key);
const presignedPost = await generatePresignedPost(CONTENT_BUCKET, keyPrefix, s3Tag);

const sanitizeResult = await this.contentSanitizer.invoke({
  presignedGetUrl: presignedGet,
  presignedPost,
  accountId,
  senderEtld1,
  contentBaseUrl: CONTENT_CDN_BASE_URL,
  keyPrefix: `accounts/${accountId}/senders/${senderEtld1}/extracted/${signalId}/`,
  retentionTag: s3Tag,
});

if (sanitizeResult.isErr()) return err(sanitizeResult.error);
const { parsed, urlMapping } = sanitizeResult.value;

// Apply URL replacements (caller-side, safe string operations)
if (parsed.htmlBody) {
  for (const [originalUrl, cdnPath] of Object.entries(urlMapping)) {
    parsed.htmlBody = parsed.htmlBody.replaceAll(originalUrl, `${CONTENT_CDN_BASE_URL}${cdnPath}`);
  }
}
```

### 2. Rule Evaluator delegates JS conditions

```typescript
async evaluate(rule: Rule, context: { signal: Signal; arc: Arc; isMatchedArc: boolean }): Promise<boolean> {
  if (rule.conditionType === "js") {
    const response = await this.userCodeExecutor.invoke({
      tenantId: context.signal.accountId,
      purpose: "rule_condition",
      functionCode: rule.code!,
      executionContext: { signal: stripSensitive(context.signal), arc: stripSensitive(context.arc) },
    });
    if (!response.success) {
      await this.annotateRuleError(rule, response.error);
      return false;
    }
    return Boolean((response as RuleExecutionResult).result);
  }
  return evalCondition(rule.condition, context);
}
```

### 3. Template function resolution

```typescript
for (const fn of template.functions) {
  const response = await this.userCodeExecutor.invoke({
    tenantId: accountId,
    purpose: "template_function",
    functionCode: fn.code,
    executionContext: { signal: stripSensitive(signal), arc: stripSensitive(arc) },
  });
  if (!response.success || (response as TemplateParameterResult).result == null) {
    await this.annotateTemplateError(template, fn.name, response.success ? null : response.error);
    templateValues[fn.name] = "";
    preventAutoSend = true;
  } else {
    templateValues[fn.name] = (response as TemplateParameterResult).result!;
  }
}
```

## Content Sanitizer — Internal Flow

```
1. Receive payload (presignedGetUrl, presignedPost, accountId, senderEtld1, contentBaseUrl, keyPrefix, retentionTag)
2. Fetch raw MIME via presignedGetUrl (plain HTTPS fetch — no AWS SDK needed)
3. Parse with mailparser → ParsedMime
4. Validate: from present, attachment count ≤ 50, total size ≤ 25MB
5. Extract attachments:
   - For each attachment: upload via presignedPost to {keyPrefix}{index} (0, 1, 2...)
   - Tag with retention value from retentionTag
   - Build AttachmentRef with cdnUrl
6. Sanitize HTML:
   a. DOMPurify: strip scripts, event handlers, forms, dangerous elements
   b. Remove CSS url() with external HTTP(S) references
   c. Collect all <img src="https://..."> URLs into a list
   d. For each external image:
      - Download (3s timeout, 5MB max)
      - Upload via presignedPost to {keyPrefix}{index} (continuing from attachment indices)
      - Add to urlMapping: originalUrl → /content/{s3Key}
   e. For each cid: reference:
      - Map to the corresponding attachment's CDN path
      - Add to urlMapping: cid:contentId → /content/{s3Key}
7. Return: { parsed (with raw htmlBody), urlMapping, attachments }
   (Caller applies urlMapping replacements to htmlBody)
```

## User Code Executor — Internal Flow

```
1. Receive payload (tenantId, purpose, functionCode, executionContext)
2. Validate: functionCode ≤ 10,000 chars, purpose is recognized
3. Create QuickJS context via quickjs-emscripten:
   - Inject signal and arc as JSON globals
   - Set interrupt handler with 800ms deadline (leaves 200ms for Lambda overhead)
4. Evaluate functionCode as: (function(signal, arc) { ... })(signal, arc)
5. Capture return value via vm.dump()
6. Serialize to JSON (fail → null)
7. Dispose context
8. Return typed response (RuleExecutionResult or TemplateParameterResult)
```

Uses `quickjs-emscripten` (already a project dependency) which runs JavaScript in a WASM-based QuickJS sandbox. This provides true isolation — user code cannot access Node.js APIs, the filesystem, network, or environment variables by design, not just by stripping globals. The Lambda boundary provides the outer security layer; QuickJS provides defense-in-depth with a proper sandbox. Timeout is enforced via `setInterruptHandler` with a deadline check.

## Pre-signed URL Generation

### Pre-signed GET (for reading the SES message)

```typescript
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { GetObjectCommand } from "@aws-sdk/client-s3";

const presignedGet = await getSignedUrl(s3, new GetObjectCommand({
  Bucket: EMAIL_BUCKET,
  Key: s3Key,
}), { expiresIn: 30 });
```

### Pre-signed POST (for uploading extracted content)

```typescript
import { createPresignedPost } from "@aws-sdk/s3-presigned-post";

const presignedPost = await createPresignedPost(s3, {
  Bucket: CONTENT_BUCKET,
  Key: `${keyPrefix}\${filename}`,  // ${filename} is a policy variable
  Conditions: [
    ["starts-with", "$key", keyPrefix],  // keyPrefix includes signalId — scoped to this message
    ["content-length-range", 0, 10 * 1024 * 1024],  // 10MB max per upload
    ...(retentionTag ? [{ "x-amz-tagging": `retention=${retentionTag}` }] : []),
  ],
  Fields: {
    ...(retentionTag ? { "x-amz-tagging": `retention=${retentionTag}` } : {}),
  },
  Expires: 30,  // 30 seconds — Lambda has 10s to use it
});
```

## Deployment

Both new Lambdas are built from the same TypeScript codebase (`email-catcher/backend`) with separate esbuild entry points:
- `src/isolated/user-code-executor.ts` → `dist/user-code-executor.js`
- `src/isolated/content-sanitizer.ts` → `dist/content-sanitizer.js`

Each is packaged as a separate zip and deployed independently. The `make.ts` build script gains two additional bundle targets.

## Error Handling Summary

| Scenario | Behavior |
|----------|----------|
| Content Sanitizer timeout (10s) | Main Lambda returns retriable error → SQS redelivers |
| Content Sanitizer parse error | Main Lambda returns retriable error → SQS redelivers |
| Content Sanitizer limits exceeded | Main Lambda returns retriable error (logged as error) |
| User Code Executor timeout (1s) | Log warning, annotate rule/template, return null |
| User Code Executor runtime error | Log warning, annotate rule/template, return null |
| User Code Executor sandbox violation | Log warning, annotate rule/template, return null |
| Image download fails (3s timeout) | Exclude from urlMapping, continue |
| Attachment upload fails | Skip attachment, continue |
| Attachment > 10MB | Skip attachment, continue |
| Image > 5MB | Exclude from urlMapping, continue |
